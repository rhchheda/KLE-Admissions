Overview

A comprehensive end-to-end admissions enquiry system

KLE Admissions System is a fully integrated platform that streamlines the admissions enquiry process for KLE Technological University. From candidate enquiries to officer discussions and analytics, everything is managed in one unified dashboard powered by Google Apps Script and real-time Google Sheets data storage.

Key Features

Everything you need for modern admissions management

📋

Admissions Enquiry Form

Interactive multi-step form with cascading campus-to-courses selection, OTP-based email verification, and real-time seat availability tracking.
👨‍💼

Officer Dashboard

Unified portal for admissions officers to manage leads, update statuses, log discussions, and prioritize candidates with starring feature.
📊

Real-time Analytics

Comprehensive analytics dashboard with KPIs, status breakdowns, trend analysis, course popularity, and campus-wise comparisons.
🔐

Secure Authentication

Role-based access control with officer login, admin privileges, and token-based email verification for candidate updates.

✉️

Smart Email Integration

Outlook-safe HTML email templates, OTP notifications, and discussion updates delivered directly to officers and candidates.

⭐

Lead Prioritization

FIFO-based lead ordering with manual starring for high-priority candidates. Officers control their own lead queue.
